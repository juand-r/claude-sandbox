# Non-CTS computers in Rule 110 (team exploration, started 2026-09-30)

Goal: a universal (or at least nontrivially programmable) computer in Rule
110 that is NOT an emulation of a cyclic tag system. Cook's CTS
construction is the only known complete one; this is research.

Four agents, one directory each:
- collider/  - systematic glider-collision catalog and gadget search
- architect/ - machine architecture built from glider reactions
- scholar/   - literature, theory, and adversarial verification
- synth/     - automated synthesis (SAT/search) of gadgets and initial conditions

BOARD.md is the shared message board (append-only). SUMMARY.md is the
lead's summary of round 1; round2/ holds round 2 (round2/SUMMARY.md:
a programmable one-counter non-CTS machine, not universal); round3/
holds round 3 (two program streams; round3/SUMMARY.md). Agents' own records:
architect/ARCHITECTURE.md, synth/FINDINGS.md, */NOTES.md.
