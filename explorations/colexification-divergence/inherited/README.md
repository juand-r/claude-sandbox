# ColexDiv: Structurally Forced Information Divergence via Colexification Asymmetries

## What this project is about

Languages carve up the world differently at the lexical level. Russian uses one
word ("noga") for both leg and foot. Spanish uses one word ("mujer") for both
woman and wife. Japanese uses one word ("kiku") for both hearing and listening.
English distinguishes all of these.

When a Russian speaker says "u menya bolit noga" (my noga hurts), they have not
committed to whether the pain is in their leg or their foot. An English
translator must choose. That choice is *forced* by the lexical structure of
English, not by editorial preference. It introduces information that was not in
the source.

This project uses CLICS4, the Database of Cross-Linguistic Colexifications, to
systematically identify where these forced divergences arise for any pair of
languages, and then tests whether LLMs handle them consistently.

## Motivation

This connects to two lines of work:

1. **X-PARADE** (Rodriguez et al., 2024): a dataset of cross-lingual
   paragraph-level information divergences, annotated at the span level. X-PARADE
   captures editorial divergences (different Wikipedia editors chose different
   facts). This project targets *structural* divergences (the target language
   forces a commitment the source language doesn't make).

2. **Multilingual LLM consistency**: when an LLM translates or generates content
   across languages, colexification asymmetries are systematic pressure points
   where inconsistency can arise. CLICS tells us exactly where to look.

## What CLICS4 is

CLICS4 is a database of ~51,000 colexification patterns across 3,447 language
varieties and 247 language families. A "colexification" is when a single word
form in a language covers two or more concepts. The database is built from
multilingual wordlists; colexification is detected by matching on phonological
form (IPA transcription).

The underlying data structure is a k-partite graph: 1,730 concept nodes shared
across all languages, with each language contributing its own word nodes linked
to concepts. CLICS publishes a one-mode projection (concept-to-concept edges
weighted by how many languages attest them), but the full structure is
recoverable from the forms table.

Key reference: Tjuka, Forkel, Rzymski & List (2026). CLICS4: An Improved
Database of Cross-Linguistic Colexifications. https://doi.org/10.5281/zenodo.16900179

## What we found

### Phase 1: Colexification asymmetries

We extracted all concept pairs from CLICS4 and identified those colexified in
many language families but not all. These are the loci of forced divergence.
The most promising pairs, with the major NLP languages on each side:

| Concept pair   | Fam | Colexify                          | Distinguish                       |
|----------------|-----|-----------------------------------|-----------------------------------|
| LEG / FOOT     | 100 | Russian, Japanese, Bengali, Turkish | English, Spanish, French, German |
| FLESH / MEAT   | 105 | Spanish, Japanese, Mandarin, German | English, Arabic                  |
| DO / MAKE      |  76 | Spanish, French, Korean, Mandarin  | Japanese, Russian, Polish         |
| BLUE / GREEN   |  70 | (various)                          | English, Japanese, Spanish        |
| WOMAN / WIFE   |  59 | Spanish, Portuguese, German, Dutch | English, Russian, French          |
| MOON / MONTH   |  60 | Japanese, Korean, Turkish          | English, Spanish, Russian         |
| HEAR / LISTEN  |  53 | Japanese, Korean, Vietnamese       | English, Spanish, French, German  |

### Phase 2: Naturally occurring examples

We collected 20 test sentences from parallel text sources (Reverso Context,
Linguee, Cornell Russian Lexical Database, Tatoeba) where the colexifying word
is used in context with varying degrees of disambiguation:

- 8 Russian sentences (LEG/FOOT)
- 6 Spanish sentences (WOMAN/WIFE)
- 6 Japanese sentences (HEAR/LISTEN)

Each sentence is annotated with: the colexifying word, the two English concepts,
and whether context disambiguates (none, weak_X, strong_X).

### Phase 3: LLM consistency test (ready to run)

A script that sends each test sentence to Claude Haiku 5 times, records which
English word it chooses, and reports consistency.

## Key technical finding about CLICS

During this project we inspected the CLICS4 source code and established that
colexification is detected by matching on the Segments column (IPA phonological
transcription), not the Form column (orthographic). The matching function in
pyclics is:

```python
for form in language.forms_with_sounds:
    cols[str(form.sounds)].append(form)
```

This means:
- Homophones with different spellings (e.g., rain/reign) ARE detected
- Homographs with different pronunciations (e.g., lead/lead) are NOT detected
- The CLDF metadata does not declare whether Form is orthographic or phonetic
  (the dc:conformsTo property is not set on the Form column)

The homophone issue is fixable: for each language, find cases where two concepts
share Segments but differ in Form. These are candidates for accidental homophony
rather than genuine semantic association.
