# LLM Usage Research

Exploration of how scientists and CS researchers use LLMs in practice — models, agents, workflows — based on empirical datasets and recent studies.

## Contents

- `REPORT.md` — Main report covering: (1) what researchers actually do with AI, (2) replication with Claude, (3) five elicitation strategies, (4) budget advice (ideation-only vs. full pipeline)

## Key Sources Investigated

- **REALM** (94K use cases, ACL 2025) — use-case taxonomy × occupation
- **WildChat-4.8M** — 4.8M real ChatGPT conversations  
- **LMSYS-Chat-1M** — 1M conversations across 25 LLMs
- **Trišović 2026** — LLM adoption lifecycles across 108K scientific papers
- **Prompt Dataset Survey** (129 datasets, EMNLP 2026) — taxonomy of 673M+ prompts
- **Robbes et al. 2026** — coding agent adoption on 128K GitHub projects
- **Murphy-Hill et al. 2026** — Claude Code vs. Copilot CLI at Microsoft
- **Agent Laboratory** / **AI Scientist** — automated research pipeline cost/quality data
- **Si et al. (ICLR 2025)** — LLM vs. human idea generation with 100+ researchers
