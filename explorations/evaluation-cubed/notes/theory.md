# Theory notes for Eval³

Working notes; the polished statements go in the paper. Notation:

- systems `s ∈ P` (a *population*), items `i ~ I`
- true quality `q(s,i) ∈ [0,1]`, `Q(s) = E_i q(s,i)`
- judge `J` gives `q̂(s,i)`, `Q̂(s) = E_i q̂(s,i)`
- error `e(s,i) = q̂(s,i) − q(s,i)`, `ē(s) = E_i e(s,i)`
- decompose `ē(s) = μ + δ(s)` with `μ = E_s ē(s)`, so `Σ_s δ(s) = 0`

## P1. Only differential bias can corrupt a ranking

`Q̂(s) − Q̂(s') = (Q(s) − Q(s')) + (δ(s) − δ(s'))`.

The global bias `μ` cancels **exactly**. The idiosyncratic part `e(s,i) − ē(s)` has zero
mean and affects only the sampling variance of `Q̂`, not its expectation.

So judge error splits into three parts with completely different consequences:

| component | effect on ranking | effect on power |
|---|---|---|
| global bias `μ` | **none** | none |
| differential bias `δ(s)` | **the entire problem** | none |
| idiosyncratic noise | none in expectation | reduces it |

Meta-evaluation accuracy is a monotone function of `E|e|`, which **mixes all three**.
That is the source of the trouble, stated in one line.

## T1. Pooled meta-evaluation cannot determine ranking validity

**Setup.** Call a meta-evaluation metric *pooled* if it is a function only of the multiset
`{(q̂(x), q(x)) : x ∈ X}` of (judge score, gold label) pairs over the evaluation set,
discarding which system produced each `x`. Item-level agreement, pairwise preference
accuracy, correlation with gold, Cohen's κ, and Brier score are all pooled. So is
essentially every number reported by current meta-benchmarks.

**Observation (the invariance).** Let `G` be the group of permutations that exchange the
judge scores of two cells carrying the *same gold label*, possibly in different systems.
Every pooled metric is `G`-invariant: the multiset is unchanged. But `Q̂(s)` — and hence
the ranking — is *not* `G`-invariant, because a swap moves score mass between systems.

**Theorem.** Let `P` contain two systems that share at least one gold-label value on at
least `m ≥ 1` items each, and let the judge's scores be non-constant within that label
class. Then for every pooled metric `M` there exist judges `J₁, J₂` with `M(J₁) = M(J₂)`
and `SRA(J₁,P) = 1`, `SRA(J₂,P) = 0`, provided the within-label score spread times `m/n`
exceeds the true quality gap.

*Proof.* Apply elements of `G` that move high judge scores from the better system's
label-`c` cells to the worse system's label-`c` cells. `M` is invariant; each swap changes
`Q̂(better) − Q̂(worse)` by a fixed negative amount; accumulate swaps until the sign
flips. ∎

**Reading.** Pooling destroys precisely the system-attribution information that determines
ranking validity. This is not a claim that current meta-benchmarks are badly designed
within their own frame; it is a claim that no amount of care in that frame can fix it.

## T2. The perturbation certificate

**Definition.** `T` is *quality-preserving* if `q(T(x)) = q(x)` for every output `x`.
Given a family `T` of such transformations, define the judge's **T-sensitivity** on a
population `P`:

    R_J(T, P) = max_{T,T' ∈ T} | mean_s Q̂(T∘s) − mean_s Q̂(T'∘s) |

`R_J` is computable from the systems' own outputs. **It uses no quality labels at all** —
only the fact that `T` preserves quality, which is a property of a transformation we wrote,
not of any system under test.

**Theorem (certificate).** Suppose the differential bias is generated by the transformation
family, i.e. `δ(s) = δ_T(s)` with `max_s δ_T − min_s δ_T ≤ R_J`. Then for any pair with

    | Q̂(s) − Q̂(s') | > R_J

the judge's ordering of `s` and `s'` is correct.

*Proof.* Say `Q̂(s) > Q̂(s')`. Then
`Q(s) − Q(s') = (Q̂(s) − Q̂(s')) − (δ(s) − δ(s')) > R_J − R_J = 0`. ∎

**Scope, stated honestly.** The certificate is sound *relative to* `T`. It bounds the
component of differential bias generated by the perturbations actually tested; it says
nothing about a confound orthogonal to `T` (say, topic mix). This is a feature, not a
dodge: it converts an unfalsifiable "trust the judge" into an explicit, extensible,
checkable list of confounds. Widening `T` strengthens the guarantee monotonically.

## T3. Where the regress terminates

The worry that motivates this project is an infinite regress: judges need meta-evaluation,
meta-evaluation needs meta-meta-evaluation, and so on without ground.

It terminates at level 3, and the reason is P1. **Rankings are invariant to the level of
quality; they depend only on differences.** Levels need external grounding. Differences do
not: a transformation with a *known* effect on quality supplies signed information about
differences without ever naming a quality value.

The sharp form of the claim is about how much external grounding is needed:

- **Level 1** (score a system): needs labels for every item. `O(items)`.
- **Level 2** (score a judge): needs labels for a meta-benchmark. `O(items)`, and it must
  be *re-collected* whenever the system population changes (T1 + the transfer result).
- **Level 3** (score a protocol): needs only that the transformation family is
  quality-preserving — a fixed, one-off, reusable assumption. `O(1)` in the number of
  systems, judges, and items.

So the regress does not terminate because we run out of patience. It terminates because
the grounding requirement stops growing. A level-4 question would ask "is `T` really
quality-preserving?", and that is a single finite assumption about `|T|` transformations we
authored, not a demand that scales with what is being evaluated.
