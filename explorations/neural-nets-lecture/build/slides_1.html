Last time

Logistic regression

Model

\[p(y = +1 \mid x) = \sigma(w \cdot x + b)\]One score, squashed into a probability.

Loss

\[\mathcal{L}(\theta; D) = \sum_i \log\bigl(1 + e^{-y_i f(x_i)}\bigr)\]Log loss on the training data \(D = \{(x_i, y_i)\}\), with \(y_i = \pm 1\).

0The model from last time: a linear score f(x) = w · x + b, through the sigmoid.

1The loss: log loss summed over the training data. (Last time we also added ½‖w‖²; we drop it from now on to keep the formulas short.)

2And the picture: one neuron. Today we change two things: more than two classes, and more than one neuron.

Two classes, rewritten

Labels as one-hot vectors

  • Write the label as a vector with a 1 for the true class:\[y = (1, 0) \quad\text{or}\quad y = (0, 1)\]
  • Give the two classes the scores \((f, 0)\). The softmax turns scores into probabilities:\[p_1 = \frac{e^{f}}{e^{f} + e^{0}} = \sigma(f)\]
  • The cross-entropy loss:\[\mathcal{L} = -\sum_k y_k \log p_k = -\log p(\text{true class})\]This is last lecture's log loss.
  • So logistic regression is softmax with two classes.

0Same data, different bookkeeping. Instead of y = +1 or −1, a vector with one entry per class.

1Divide top and bottom by e^f: 1/(1 + e^(−f)), the sigmoid. Fixing the second score at 0 loses nothing: only the difference of the two scores matters.

2Only the true class's term survives, because the other entries of y are 0. −log σ(f) for a positive, −log(1 − σ(f)) for a negative: the log loss we derived last time.

3This rewriting is what lets us go to more than two classes on the next slide.

More than two classes

Softmax and cross-entropy

  • One score per class:\[z_k = w_k \cdot x + b_k, \quad k = 1, \dots, C\]
  • Softmax:\[p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}\]Positive, and they sum to 1.
  • Cross-entropy:\[\mathcal{L} = -\sum_i \log p(\text{true class of } i)\]
  • Example: \(z = (2, 1, -1)\) gives \(p = (0.71, 0.26, 0.04)\). If the true class is 1, the loss is \(-\log 0.71 = 0.35\).

0N input features on the left, C outputs on the right. Each output has its own weight vector: C logistic regressions side by side.

1Exponentiate and normalize. The largest score gets the largest probability; the exponential makes them positive.

2For one point it is −log of the probability given to the class it really belongs to. Confident and wrong is expensive: −log 0.01 ≈ 4.6.

3e² ≈ 7.39, e¹ ≈ 2.72, e⁻¹ ≈ 0.37, sum ≈ 10.48. If the true class were 3, the loss would be −log 0.035 ≈ 3.3.

How to train it?

The loss landscape

  • The loss depends on the parameters \(\theta\). Picture it as a surface over \(\theta\).
  • The gradient is the vector of partial derivatives:\[\nabla\mathcal{L} = \left(\frac{\partial\mathcal{L}}{\partial\theta_1}, \frac{\partial\mathcal{L}}{\partial\theta_2}\right)\]It points uphill, the steepest way up.
  • Step the other way, again and again: gradient descent.
  • A different start can end in a different minimum.
  • Logistic regression's loss is a single bowl: one minimum. A network's loss is not.

A made-up loss surface with two parameters.

0A cartoon: real models have thousands of parameters, but two are enough to draw. Darker means lower loss. Two valleys.

1Each partial derivative is the slope in one direction. Together they form an arrow pointing uphill. Its length is how steep it is.

2From the amber start, take a small step against the gradient, recompute, repeat. The path follows the slope down into the nearest valley. The start point can be dragged.

3Start somewhere else and the same procedure ends in the other, shallower valley: a local minimum. Gradient descent only sees the slope where it stands.

4Logistic regression's loss is convex: any start reaches the same answer. Neural networks lose that guarantee. We come back to this next class.

How to train it?

Gradient descent

  • Update all parameters at once:\[\theta \leftarrow \theta - \eta\, \nabla\mathcal{L}(\theta)\]\(\eta\) is the learning rate.
  • Too small: many tiny steps.
  • About right: a few steps to the minimum.
  • Too large: it overshoots and the loss goes back up.

History

The perceptron (1958)

  • Rosenblatt's perceptron uses the same score \(f(x) = w \cdot x + b\).
  • A step instead of the sigmoid: predict the sign of \(f(x)\).
  • Its learning rule, on a mistake:\[w \leftarrow w + \eta\, y_i x_i, \quad b \leftarrow b + \eta\, y_i\]
  • That is gradient descent, one point at a time, on the loss \(\max(0, -y\, f(x))\).

0Frank Rosenblatt, at the Cornell Aeronautical Laboratory. The Mark I Perceptron was a machine: photocells for the input, motor-driven potentiometers for the weights, and wires like these. Same linear score as logistic regression and the SVM.

1No probability: the output is +1 or −1.

2Labels ±1. When a point is misclassified, move the line towards classifying it correctly. Correct points change nothing.

3The loss is 0 for correct points and −y f(x) for wrong ones: the hinge loss without the margin. Same model family as logistic regression and the SVM; a different loss and a different way to minimize it.

History

Perceptrons (1969)

They proved what single-layer perceptrons cannot compute. XOR is the simplest example.

0Marvin Minsky and Seymour Papert, both at MIT. Their book analyzed exactly what a single layer of perceptrons can and cannot represent.

1Careful with the popular story. Networks with more layers were known to be more powerful; what was missing was a practical way to train them. That came with backpropagation, popularized in 1986, which is next class. How much the book itself caused the drop in funding that followed is debated by historians.

Fixing XOR

Add a hidden layer

  • Start from one neuron.
  • Copy it: each hidden neuron is a logistic regression on the inputs.
  • Feed the hidden neurons to the outputs: a softmax on the hidden neurons.
  • Feed-forward and fully connected: a multilayer perceptron (MLP).

0One neuron: two inputs, a weighted sum, a sigmoid.

1Three copies, each with its own weights. Each one draws its own line through the input space and reports which side a point is on, softly.

2The output layer combines those reports. It is the softmax model from earlier, applied to new features that the hidden layer computes.

3Feed-forward: information flows left to right, no loops. Fully connected: every node feeds every node of the next layer. "Perceptron" is historical; the units are sigmoids, not steps.

What the network computes

Forward propagation

\[\begin{aligned} h &= \sigma(W_1 x + b_1) \\ z &= W_2 h + b_2 \\ p &= \operatorname{softmax}(z) \end{aligned}\]
  • Shapes: \(x\) has \(N\) entries, \(W_1\) is \(H \times N\), \(W_2\) is \(C \times H\). The parameters are \(\theta = (W_1, b_1, W_2, b_2)\).
  • The loss is the same cross-entropy.
  • Why the sigmoid? Without it, the layers collapse into one linear layer:\[W_2(W_1 x + b_1) + b_2\]\[= (W_2 W_1)\, x + (W_2 b_1 + b_2)\]

0Three lines. Multiply by a matrix, add a vector, apply σ to every entry; then the output layer. Propagating forward means evaluating these left to right.

1For XOR: N = 2 inputs, H = 3 hidden units, C = 2 classes, so W₁ is 3 × 2 and W₂ is 2 × 3. 17 numbers in total, counting the biases.

2Nothing new: −log of the probability of the true class, summed over the training data.

3A product of matrices is a matrix. Without a nonlinearity between them, any number of layers is still one linear model, one line, and XOR stays unsolved.

Check it by hand

XOR with two hidden units

  • Inputs 0 or 1.
  • \(h_1 = \sigma(20x_1 + 20x_2 - 10)\): about 1 if either input is 1. That is OR.
  • \(h_2 = \sigma(20x_1 + 20x_2 - 30)\): about 1 only if both are. That is AND.
  • \(f = 20h_1 - 20h_2 - 10\), \(p = \sigma(f)\): OR and not AND. That is XOR.
\(x_1\)\(x_2\)\(h_1\) (OR)\(h_2\) (AND)\(f\)\(p\)

0Four possible inputs. We will set the weights by hand, not train them.

1σ(−10) ≈ 0.00005 and σ(10) ≈ 0.99995. With both inputs 0 the score is −10; with one or two inputs on it is +10 or +30.

2Same weights, bias −30: only both inputs together get the score above 0.

3One output score with a sigmoid is the two-class softmax with scores (f, 0) from earlier. p is the probability of "XOR = 1". Each hidden unit draws one line; the output combines the two lines. Training finds weights like these on its own.

Summary

Takeaways

Softmax

One score per class, softmax for probabilities, cross-entropy as the loss. Two classes: logistic regression.

Gradient descent

\(\theta \leftarrow \theta - \eta\, \nabla\mathcal{L}\). The learning rate sets the step size.

One line is not enough

The perceptron and logistic regression cannot do XOR.

Hidden layers

\(h = \sigma(W_1 x + b_1)\), then softmax. The hidden units learn the features.
