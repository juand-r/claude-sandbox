Losses for a classifier

  • A score \(f(x)\) and a label \(y = \pm 1\). Predict \(+1\) when \(f(x) > 0\).
  • Multiplying by the label turns both correct cases into \(y\, f(x) > 0\):
    \(y\)\(f(x)\)\(y\, f(x)\)
    \(+1\)\(> 0\)\(> 0\)correct
    \(+1\)\(< 0\)\(< 0\)mistake
    \(-1\)\(< 0\)\(> 0\)correct
    \(-1\)\(> 0\)\(< 0\)mistake
  • 0–1 loss: \(\mathbf{1}\bigl[y\, f(x) \le 0\bigr]\), which is 1 for a mistake and 0 otherwise.
  • Hinge loss (SVM): \(\max\bigl(0, 1 - y\, f(x)\bigr)\).
  • Log loss (logistic regression): \(\log\bigl(1 + e^{-y f(x)}\bigr)\).

━ 0–1 loss━ hinge loss━ log loss

0A review of last lecture, slowly, because today builds on it. The model gives a score; its sign is the prediction.

1Go through the four rows. For y = +1, y f(x) is just f(x). For y = −1, y f(x) is −f(x), and "f(x) < 0" is the same as "−f(x) > 0". So in both correct rows y f(x) is positive, and in both mistake rows it is negative. That is why the horizontal axis of the plot is y f(x): right of 0 is correct, left of 0 is a mistake.

2The indicator 1[·] is 1 when the statement in the brackets is true, 0 when it is false. Added up over the training data, it counts the mistakes. As a curve: 1 on the left, 0 on the right, a jump at 0. It is flat everywhere else, so it gives no direction in which to improve.

3The SVM's hinge loss: zero once y f(x) ≥ 1, outside the margin, and growing linearly below that.

4Logistic regression's log loss: smooth, never exactly zero, and close to a straight line far on the wrong side, like the hinge. At y f(x) = 0 it is log 2 ≈ 0.69.

Logistic regression

Model

\[f(x) := w \cdot x + b\]\[p(y = +1 \mid x) = \sigma\bigl(f(x)\bigr)\]One score, squashed into a probability.

Loss

\[\mathcal{L}(\theta; D) = \sum_i \log\bigl(1 + e^{-y_i f(x_i)}\bigr)\]Log loss on the training data \(D = \{(x_i, y_i)\}\), with \(y_i = \pm 1\).

0The model from last time: the linear score f(x) = w · x + b, and the sigmoid of the score as the probability of the positive class. f is the score, not the probability.

1The loss: log loss summed over the training data. (Last time we also added ½‖w‖²; we drop it from now on to keep the formulas short.)

2And the picture: one neuron. Today we connect many of these neurons, and allow more than two classes.

Last time

Confident and wrong costs a lot

  • The log loss of one point is\[-\log p(\text{true class})\]
  • The 0–1 loss (dotted) only asks whether \(p(\text{true class})\) is above 0.5.

0Last time we saw that the log loss is −log of the probability the model gives to the class the point really belongs to. In formulas: p(true class) = σ(y f(x)), and −log σ(y f(x)) = log(1 + e^(−y f(x))). Right and sure: almost free. Unsure: about 0.7. Wrong and sure: expensive, and without limit as p(true class) goes to 0.

1With a threshold of 0.5, a point is a mistake exactly when p(true class) < 0.5. The 0–1 loss charges 1 for any mistake, however confident. The log loss charges more for confident mistakes, and a little even for unsure correct answers.

From neuron to model

A very simplified neuron

F. Rosenblatt, "The perceptron: a probabilistic model for information storage and organization in the brain", Psychological Review 65(6) (1958), 386–408.

0A real neuron. The dendrites, the branches around the cell body, receive signals from other neurons. The cell body combines them. If the combined signal is strong enough, the neuron fires: a pulse runs down the axon to the synaptic terminals, which pass it on to other neurons. Some connections are stronger than others.

1The model keeps only the outline. Inputs play the dendrites, weights the connection strengths, a weighted sum the cell body, a threshold the decision to fire, and the output the axon. The bias is one more weight, on an input that is always 1. Everything else about real neurons, such as timing, chemistry and the shapes of the cells, is left out.

2McCulloch and Pitts (1943) described neurons as threshold units and showed that networks of them can compute logical functions; their weights were set by hand. Rosenblatt (1958) made the weights learnable from examples: the perceptron, a bonus slide at the end.

Where the name comes from

Networks of neurons

Real neurons, stained so that their branches show. Each cell reaches out to many others, and the whole forms a dense web. "Neural network" borrows the picture: many simple units, connected. Next: connect our simplified neurons.

A hidden layer

Combining multiple neurons

  • Start from one neuron.
  • Copy it: each hidden neuron is a logistic regression on the inputs.
  • Feed the hidden neurons to one output neuron: a logistic regression on the hidden neurons, trained with the log loss.
  • Feed-forward and fully connected: a multilayer perceptron (MLP).

0One neuron: two inputs, a weighted sum, a sigmoid.

1Three copies, each with its own weights. Each one draws its own line through the input space and reports which side a point is on, softly.

2The output neuron combines those reports. It is last lecture's logistic regression, applied to new features that the hidden layer computes, and the loss is the same log loss. More than one output neuron: next.

3Feed-forward: information flows left to right, no loops. Fully connected: every node feeds every node of the next layer. "Perceptron" is historical; the units are sigmoids, not steps.

More than two classes

Softmax

  • One output score per class: \(z_1, z_2, z_3\) for \(C = 3\) classes.
  • The softmax turns the scores into probabilities:\[p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}\]They are positive and sum to 1.
  • Example: \(z = (2, 1, -1)\) gives \(p_1 = 0.71\), \(p_2 = 0.26\), \(p_3 = 0.04\).
  • Predict the class with the largest \(p_k\).

0Three classes, so three output neurons, each with its own weights. Each one takes all four hidden neurons as its inputs. (Without a hidden layer, they would take the features directly.)

1Exponentiate, then divide by the total. The exponential makes every score positive; dividing makes them sum to 1. The largest score gets the largest probability.

2e² ≈ 7.39, e¹ ≈ 2.72, e⁻¹ ≈ 0.37, sum ≈ 10.48. Divide each by the sum.

3The prediction is the most probable class. The probabilities themselves are what the loss will use.

Two classes

Softmax with two classes is the sigmoid

  • With two classes, give them the scores \((f, 0)\).
  • The softmax of these scores:\[p_1 = \frac{e^{f}}{e^{f} + e^{0}} = \frac{1}{1 + e^{-f}} = \sigma(f)\]
  • So one output neuron with a sigmoid is a two-class softmax: last lecture's logistic regression.

0Why can one of the scores be 0? The softmax only depends on the differences between scores: adding the same number to every score changes nothing. So with two classes we can fix the second score at 0.

1Divide top and bottom by e^f: 1/(1 + e^(−f)), the sigmoid.

2This is why one output neuron with a sigmoid was enough for two classes. With three or more classes we need the softmax.

What the network computes

Forward propagation

\[\begin{aligned} h &= \sigma(W^{(1)} x + b^{(1)}) \\ z &= W^{(2)} h + b^{(2)} \\ p &= \operatorname{softmax}(z) \end{aligned}\]
  • Shapes: \(x\) has \(N\) entries, \(W^{(1)}\) is \(H \times N\), \(W^{(2)}\) is \(C \times H\). The parameters \(\theta\) are \(W^{(1)}\), \(b^{(1)}\), \(W^{(2)}\) and \(b^{(2)}\). The superscript is the layer.
  • Why a nonlinearity? Without one, the layers collapse into one linear layer:\[W^{(2)}(W^{(1)} x + b^{(1)}) + b^{(2)}\]\[= (W^{(2)} W^{(1)})\, x + (W^{(2)} b^{(1)} + b^{(2)})\]Any nonlinear function \(\varphi\) works; the sigmoid is one choice.

0Three lines. Multiply by a matrix, add a vector, apply σ to every entry; then the output layer and the softmax. Propagating forward means evaluating these left to right.

1In the picture: N = 2 inputs, H = 3 hidden units, C = 3 classes, so W⁽¹⁾ is 3 × 2 and W⁽²⁾ is 3 × 3. 21 numbers in total, counting the biases. In the picture each bias is a weight from an extra node whose value is always 1, so a bias is just one more weight.

2A product of matrices is a matrix. Without a nonlinearity between them, any number of layers is still one linear model: with two classes, one line. Any nonlinear function prevents the collapse; the next slide shows the common ones.

Not only sigmoids

Activation functions

  • The function each hidden neuron applies is its activation function \(\varphi\):\[h = \varphi(W^{(1)} x + b^{(1)})\]
  • Sigmoid, \(\sigma(a) = 1 / (1 + e^{-a})\): between 0 and 1.
  • \(\tanh(a)\): between −1 and 1, a rescaled sigmoid.
  • ReLU, \(\max(0, a)\): 0 for negative inputs, the input itself for positive ones. Widely used in deep networks.
  • The output layer stays the same: the softmax, or \(\sigma\) for two classes.

0φ is the Greek letter phi. Each hidden neuron computes a weighted sum a and then outputs φ(a). Until now φ was the sigmoid, but any nonlinear function stops the layers from collapsing into one.

1The one we have used so far. Its slope is σ(a)(1 − σ(a)): at most 1/4, at a = 0, and close to 0 when a is far from 0.

2tanh(a) = 2σ(2a) − 1: the sigmoid stretched to the range (−1, 1) and centred at 0. Its slope at 0 is 1.

3The rectified linear unit. It is cheap to compute, and its slope is 1 for every positive input, so it does not flatten out for large inputs the way the sigmoid does. It has no derivative at exactly 0. Any value between 0 and 1 can be used there; it rarely matters, because a sum is seldom exactly 0.

4The activation function is a choice for the hidden layers. The output layer has a different job, turning scores into probabilities, so it keeps the softmax. The examples in this lecture and the next use sigmoid hidden units.

More layers

Deeper networks

  • Stack hidden layers. Each layer works on the output of the one before:\[h^{(l)} = \varphi\bigl(W^{(l)} h^{(l-1)} + b^{(l)}\bigr)\]for \(l = 1, \dots, L - 1\), starting from \(h^{(0)} = x\).
  • The last layer is the softmax:\[p = \operatorname{softmax}\bigl(W^{(L)} h^{(L-1)} + b^{(L)}\bigr)\]
  • Many hidden layers: a deep network, hence "deep learning".

0The same step as before, repeated, with an activation function φ such as the sigmoid or ReLU. h⁽ˡ⁾ is the output of layer l; the input counts as layer 0. W⁽ˡ⁾ and b⁽ˡ⁾ connect layer l − 1 to layer l. The picture has L = 3: two hidden layers, then the output layer with three classes.

1With one hidden layer, L = 2, and these are exactly the equations of the last slide, with h⁽¹⁾ = h.

2Each layer can build features out of the previous layer's features. How to train all these weights: next class, and the same method works for any number of layers.

Why hidden layers?

Logistic regression can't learn XOR

The XOR data from the SVM lecture: 24 points, 6 per corner, green in two opposite corners and purple in the other two. Logistic regression draws one line, and any line leaves at least one corner on the wrong side. Fitted with no penalty, the best it can do is give up: the data are symmetric, so the fit is w = 0, p = 0.5 everywhere, 50% accuracy. The perceptron has the same problem. In the SVM lecture we fixed this with a kernel, a feature map we chose by hand. A hidden layer lets the network build its own features. XOR needs only one hidden layer, with two neurons; more layers pay off on harder problems.

XOR with two hidden units

  • Inputs 0 or 1.
  • \(h_1 = \sigma(20x_1 + 20x_2 - 10)\): about 1 if either input is 1. That is OR.
  • \(h_2 = \sigma(20x_1 + 20x_2 - 30)\): about 1 only if both are. That is AND.
  • \(f = 20h_1 - 20h_2 - 10\), \(p = \sigma(f)\): OR and not AND. That is XOR.
\(x_1\)\(x_2\)\(h_1\) (OR)\(h_2\) (AND)\(f\)\(p\)

2Same weights, bias −30: only both inputs together get the score above 0.

Training

How do we choose the weights?

  • For XOR we set them by hand. Real networks have thousands or millions of weights.
  • Choose the weights that make a loss on the training data small.
  • Two questions: which loss, and how to make it small.

0So far we have the structure: what a network computes from its weights. Now: where the weights come from.

1Exactly as for logistic regression: a model with parameters, and a loss that scores each choice of parameters on the training data.

2The loss: cross-entropy, next. Making it small: gradient descent, after that.

The loss

Cross-entropy

  • Write the label as a one-hot vector, with a 1 for the true class: \(y = (1, 0, 0)\) for class 1.
  • The cross-entropy of one point:\[\mathcal{L} = -\sum_k y_k \log p_k = -\log p(\text{true class})\]Add it up over the training data.
  • With \(p = (0.71, 0.26, 0.04)\): if the true class is 1, the loss is 0.35; if it is 3, the loss is 3.35.
  • With two classes, it is last lecture's log loss.

0Same information as the label, different bookkeeping: one entry per class.

1Only the true class's term survives, because the other entries of y are 0. So it is the same −log p(true class) as before, now with C classes.

2The probabilities from the softmax example. −log 0.705 = 0.35, and −log 0.035 = 3.35 (using the unrounded probabilities). The less probable the true class, the larger the loss.

3With two classes and the sigmoid, −log p(true class) = log(1 + e^(−y f(x))), the log loss we started with today.

Putting it together

Multilayer perceptrons

Model

\[h^{(0)} = x, \quad h^{(l)} = \varphi\bigl(W^{(l)} h^{(l-1)} + b^{(l)}\bigr)\]\[p = \operatorname{softmax}\bigl(W^{(L)} h^{(L-1)} + b^{(L)}\bigr)\]\(\varphi\) is the activation function. The parameters \(\theta\) are all the weights and biases.

Loss

\[\mathcal{L}(\theta) = -\sum_i \log p(\text{true class of } x_i)\]Cross-entropy, added up over the training data.

0The model: the forward propagation equations, for any number of layers. Layers 1 to L − 1 are hidden; layer L is the output.

1The loss: cross-entropy, added up over the training points. Training means finding the θ with the smallest loss, the same recipe as for logistic regression.

2The general picture: the input, any number of hidden layers, and an output layer with a softmax. Next: how to make the loss small.

How to train it?

The loss landscape

  • The loss depends on the parameters \(\theta\). Picture it as a surface over \(\theta\).
  • The gradient is the vector of partial derivatives:\[\nabla\mathcal{L} = \left(\frac{\partial\mathcal{L}}{\partial\theta_1}, \frac{\partial\mathcal{L}}{\partial\theta_2}\right)\]It points uphill, the steepest way up.
  • Step the other way, again and again: gradient descent.
  • A different start can end in a different minimum.
  • Logistic regression's loss is a single bowl: one minimum. A network's loss is not.

A made-up loss over two parameters. Left: the height is the loss. Right: the same surface seen from above.

0A cartoon: real models have thousands of parameters, but two are enough to draw. Left, the surface in 3D: the height is the loss. Right, the same surface seen from above, like a map; darker means lower. Two valleys, one deeper than the other (the stars).

1Each partial derivative is the slope in one direction. Together they form an arrow in the parameter plane, on the right, pointing in the direction of steepest ascent. On the left, the same direction followed along the surface: it goes uphill. (Drawn with a fixed length; the true length is how steep the slope is.)

2From the amber start, take a small step against the gradient, recompute, repeat. The path follows the slope down into the nearest valley. The start point can be dragged in either view; dragging the background of the 3D view turns it.

3Start somewhere else and the same procedure ends in the other, shallower valley: a local minimum. Gradient descent only sees the slope where it stands.

4Logistic regression's loss is convex: any start reaches the same answer. Neural networks lose that guarantee. We come back to this next class.

How to train it?

Gradient descent

  • Update all parameters at once:\[\theta \leftarrow \theta - \eta\, \nabla\mathcal{L}(\theta)\]\(\eta\) is the learning rate.
  • Too small: many tiny steps.
  • About right: a few steps to the minimum.
  • Too large: it overshoots and the loss goes back up.

Summary

Takeaways

Structure

Neurons in layers, each applying an activation function such as the sigmoid or ReLU. Hidden layers learn features, so XOR becomes possible.

Softmax

One score per class, turned into probabilities. With two classes it is the sigmoid.

Loss

Cross-entropy, \(-\log p(\text{true class})\). Confident and wrong costs a lot.

Training

Gradient descent, \(\theta \leftarrow \theta - \eta\, \nabla\mathcal{L}\). The learning rate sets the step size.

Bonus

The perceptron (1958)

  • Rosenblatt's perceptron uses the same score as logistic regression, \(f(x) = w \cdot x + b\), but without the sigmoid.
  • A step instead of the sigmoid: predict the sign of \(f(x)\).
  • Its learning rule, on a mistake:\[w \leftarrow w + \eta\, y_i x_i, \quad b \leftarrow b + \eta\, y_i\]
  • That is gradient descent, one point at a time, on the loss \(\max(0, -y\, f(x))\).

0Frank Rosenblatt, at the Cornell Aeronautical Laboratory. The Mark I Perceptron was a machine: photocells for the input, motor-driven potentiometers for the weights, and wires like these. Same linear score as logistic regression and the SVM.

1No probability: the output is +1 or −1.

2Labels ±1. When a point is misclassified, move the line towards classifying it correctly. Correct points change nothing.

3The loss is 0 for correct points and −y f(x) for wrong ones: the hinge loss without the margin. Same model family as logistic regression and the SVM; a different loss and a different way to minimize it.
