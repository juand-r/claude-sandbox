# Review pass 3: original, annotated review, honest rewrite

September 2026. Read-only review: nothing in the annotated edition or the honest rewrite was changed during this pass.

For each post I read, in order:
1. the original post (`data/originals/<slug>.md`);
2. the annotated edition's summary and review: the margin notes (`\cpara`, `\clogic`) in `annotated/posts/<slug>.tex` and the afterword (summary and response) in `annotated/afterwords/<slug>.tex`;
3. the honest rewrite (`honest/sections/<slug>.tex`).

Labels used below:
- **ANN**: a problem in the annotated review (margin notes or afterword).
- **ANN≠HON**: the annotated review says something the honest rewrite has since corrected or dropped, so the two editions disagree.
- **HON**: a problem that remains in the honest rewrite.
- **OK**: checked and found sound; noted only where it was in doubt.

Severity: **error** (wrong about the post or the facts), **unfair** (a defender would win), **weak** (defensible but thin, or a nitpick), **style** (voice or clarity only).
