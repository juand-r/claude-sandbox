# Reporting-tag pass (user request, 30 September 2026)

The user: "I noticed you use a lot of `I say,'... followed by what is said. This is
cumbersome. Find this and similar cases (I forget the actual phrasings) to fix it."

The cases are reporting tags: "the post says", ", the author says,", "It says that",
"is said to", "says that" and the like. A search found 464 sentences in 255 afterwords;
each is read in context and rewritten by these rules:

1. In a Summary, the whole section reports the post, so a tag is usually dropped. It stays
   (or becomes a precise verb) only where the reader could otherwise take the claim as ours.
2. In a Response, attribution matters, because we separate the post's claims from our
   judgment. There the tag is kept short and put first ("The post claims X"), or the claim
   is quoted, or the sentence is rebuilt around the post's act ("calls", "asserts",
   "concedes"). No tags that interrupt the sentence (", the post says,").
3. "Says" is replaced by the verb that states what the post does: claims, argues, asserts,
   grants, calls, predicts, recommends.
4. No change to what is claimed; hedges stay.

Edits are logged in `docs/raz/changes/says_pass.md`.
