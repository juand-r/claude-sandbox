# Report: disguised-queries

## 1. The argument in three sentences

In an invented sorting factory, blue eggs ("bleggs") and red cubes ("rubes") differ in many
correlated features, and it turns out that they are sorted because bleggs usually contain
vanadium and rubes palladium. An object that looks like a blegg but contains palladium goes in
the rube bin, yet should be expected to glow like a blegg, so "Is it a blegg?" stands for
different practical questions ("which bin?", "will it glow?") on different occasions, and would
not matter if it stood for none. Arguments over whether atheism is a "religion" are such
disguised queries about empirical clusters, and consulting a dictionary cannot settle them,
because redrawing a word's boundary does not move anything in the world.
