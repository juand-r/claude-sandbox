# Report: 2-place-and-1-place-words ("2-Place and 1-Place Words", Yudkowsky, posted 2008-06-27; book order 275)

## 1. The argument in three sentences (written before annotating)

The pulp artist who thinks a bug-eyed monster will find a human woman sexy treats sexiness,
a function of two arguments (admirer, entity), as a function of one (entity), which is a
variable question fallacy or mind projection fallacy. An "equally valid" alternative is that
each speaker's "sexy" names a different one-place function that makes no mention of the
speaker (Fred's is Sexiness_20934, Bloogah's Sexiness_72546), and currying unifies the two
views: the two-place word eats an admirer and returns a fixed one-place function; the same
analysis dissolves the Twin Earth debate about "water", which, the post says, rested on
instinctively currying or uncurrying concepts. One must train oneself to be aware of the
curried and uncurried forms, because the brain by instinct labels its own function
"Woman.sexiness"; the analysis will be used later to taboo "objective", "subjective" and
"arbitrary".
