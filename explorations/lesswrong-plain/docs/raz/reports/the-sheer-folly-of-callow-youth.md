# Report: the-sheer-folly-of-callow-youth

Batch 6a (Book VI, Yudkowsky's Coming of Age, order 303). Posted 2008-09-19.

## 1. The argument in three sentences

The author's early "mysterious answer" concerned morality as well as consciousness: in 1997 the
young author argued that the case "life is meaningless" cancels out of any expected-utility
calculation, so one may act as if life has meaning and build a superintelligence to find that
meaning, and treated the "ought" problem, existence and qualia as linked "hard problems" needing
new physics. The author diagnoses the errors as treating utility as an absolute quantity,
treating "should" as whatever compels any mind (and equating that with "right"), and using the
"proof" as a reason not to define "intelligence" or "meaning", and says the young author did not
turn on this position the refutation skill used on others. The lessons: no justification for
relaxing rigor protects you, because Nature grades only whether you meet the standard; one may
think with vague concepts but not put one's weight on a "best guess" or build on an interim
understanding; and confusion cannot be worked around, only dissolved.

## 3. Arithmetic

No arithmetic in the post. The utility point was checked by hand: if in the "meaningless" branch
every action has the same utility c, then EU(A) = p·U_P(A) + (1−p)·c, and the ranking of actions
is that of U_P for any c and any p > 0; so c = 0 and c = 100 behave alike, as the post says.
(The FAQ's step 7 renormalizes by dividing by the sum of values, which does depend on the zero
point; the post does not discuss this and neither do the notes.)

"Five days later": Sheer Folly 2008-09-19, Fighting a Rearguard Action 2008-09-24. "Three days
earlier": My Best and Worst Mistake 2008-09-16. "The day before": A Prodigy of Refutation
2008-09-18. "Four months later": Value is Fragile 2009-01-29.

## 6. Judgment calls for the editor

- Reserved words: "wrong" appears only as a paraphrase of the post ("so that it would be clear
  the 1997 view was wrong", the post's "had gotten it wrong"). "refute" describes the post.
- The first-lesson note and Response ("a rule for every case, drawn from one case, which shows
  that relaxing rigor can fail, not that it always does"). A fair defender might say a memoir's
  moral is a maxim, not an empirical claim. I kept it because the wording is universal ("No
  matter how ... it will"). The editor may prefer to cut it to scope.
- The premise note (answer to haste rests on "a best guess fails as surely as no attempt",
  argued in Value is Fragile). I read "Either you match it, or you fail" as that premise. It is
  now neutral information with a pointer; check the Response paragraph that uses it.
- The moral-uncertainty note: one book (MacAskill, Bykvist and Ord) stands for "later work";
  the Response says "a recent book". I did not use Jacob Ross, "Rejecting Ethical Deflationism"
  (Ethics 116, 2006), whose abstract I could not fetch verbatim (Crossref confirms the citation).
- Rumsfeld cpara is information only; the post's gloss ("went to war with the army he had")
  fits Rumsfeld's own words, so no fault is charged.
- The alchemists note ("Loosely put") rests on one Wikipedia article; I found no Western case
  documented there. The point of the post's sentence survives, so it is not in the In short line.
- Penrose credit: My Wild and Reckless Youth already names Penrose, so this is not a
  "no credit" charge, only information.
- Honest section is 519 words, slightly over the 500 guideline.
