# Report: could-anything-be-right ("Could Anything Be Right?", Yudkowsky, posted 2008-07-18; book order 278)

## 1. The argument in three sentences (written before annotating)

The author's 1999 self claimed to know nothing about morality and hoped a generic
superintelligence could discover it; but a belief with no correct content is not about anything
(Davidson), and a program can only compute "morality" if something in its start state points
it there (no-free-lunch), so total moral ignorance leaves the words "right" and "should" without
meaning. As a scientist's notion of evidence can change only because the brain already contains
dispositions that new arguments appeal to, you must accept that what your brain would recognize
as right is what "right" is about, which means rejecting both a wholesale distrust of evolved
intuitions and a morality lying wholly outside human reach. Once some content is built into the
question "what is right?", there is no reason not to build in more, such as that joy is, other
things equal, preferable to sorrow, so you know quite a lot about morality, revisably, and the
claim is about the meaning of the words, not an argument by definition.
