# Report: could-anything-be-right ("Could Anything Be Right?", Yudkowsky, posted 2008-07-18; book order 278)

## 1. The argument in three sentences (written before annotating)

The author's 1999 self claimed to know nothing about morality and hoped a generic
superintelligence could discover it; but a belief with no correct content is not about anything
(Davidson), and a program can only compute "morality" if something in its start state points
it there (no-free-lunch), so total moral ignorance leaves the words "right" and "should" without
meaning. As a scientist's notion of evidence can change only because the brain already contains
dispositions that new arguments appeal to, you must accept that what your brain would recognize
as right is what "right" is about, which means rejecting both a wholesale distrust of evolved
intuitions and a morality lying wholly outside human reach. Once some content is built into the
question "what is right?", there is no reason not to build in more, such as that joy is, other
things equal, preferable to sorrow, so you know quite a lot about morality, revisably, and the
claim is about the meaning of the words, not an argument by definition.

## 6. Judgment calls

1. The two placement notes (P31 clogic: analytic descriptivism, Jackson; P28 clogic: the
   disagreement objection). The post takes a side on what "right" is about ("that which your
   brain would recognize as right is what you are talking about"; intuitions "baked into the
   question"), so the brief allows a placement and the main objection. I wrote "resembles", not
   "is": the post does not say moral properties are natural properties, which Jackson's view
   does. The later posts in the book may address human disagreement; I checked only that this
   post does not (it discusses disagreement only for the ghost), and the scope sentence is
   limited to "this post".
2. P29 note: "The extension is made by a question ... it did not show which intuitions belong to
   the meaning of the question rather than to its answers." A fair defender could say "why not
   accept it for now" is offered as a proposal, not a proof. The note says it is a question, and
   claims only that the earlier argument does not select the intuitions. It is also in the
   Response and one n.b.
3. P27 note on realism: the post's target is Eliezer1999's view, so the note does not call the
   contrast a straw man; it only says the view rejected is stronger than realism as the SEP
   defines it.
4. "Sound" is used of the post's first argument (Response and In short). That is credit, kept
   because leaving it out would mislead: the Davidsonian premise is used in its weak form.
5. Reserved words: "wrong" and "never" occur only in describing the post's content (killing
   probably wrong; a morality humans would never be moved to adopt). "his" is inside a quotation
   of the post (Eliezer1999's "explicitly represented philosophy").
6. Socrates: I considered an information note on "The only thing I know is that I know nothing"
   (a later compression of Plato's Apology) and dropped it as a nitpick; the post calls it a
   saying ("and all that").
