# Report: reductionism ("Reductionism", Yudkowsky, posted 2008-03-16)

## 1. The argument in three sentences (written before annotating)

Reductionism, in the author's sense, is obviously correct: physics describes a 747 and a
collision of gold nuclei with the same fundamental laws, and we use different, simpler
models for the airplane only because a fundamental model would be impossibly expensive to
compute, so the use of different levels of description is a fact about our maps, not about
the territory. A fundamental model would contain all the facts about wings and lift
implicitly, and would predict better; the feeling that the airplane is made of many
interacting levels is how an efficient multi-level model in the mind feels from inside.
Reductionism is therefore not a positive belief but a disbelief that the higher levels of
our models exist in the territory, which dissolves the question of how the airplane can
lack "real" wings when one can see them.
