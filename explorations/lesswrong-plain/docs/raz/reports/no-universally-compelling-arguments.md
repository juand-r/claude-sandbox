# Report: no-universally-compelling-arguments ("No Universally Compelling Arguments", Yudkowsky, posted 2008-06-26; book order 272)

## 1. The argument in three sentences (written before annotating)

Since mind design space is vast, for any argument there is some possible mind it does not
persuade; the hope for arguments that would persuade any mind comes from picturing a "ghost in
the machine", an irreducible core of reasonableness above the code, whereas physically, for any
system that assents to an argument one can build a similar system that does not, so compulsion
is a property of minds, not of arguments. The same holds for the charge that Bayesian priors are
"arbitrary": the ideal philosopher of perfect emptiness who would be persuaded from no
assumptions is the ghost again, and a mind with all assumptions removed is a rock, so validity,
rationality or objectivity cannot rest on universal compellingness. The worst error in thinking
about Friendly AI is to expect any AI to reach the one true morality on its own (a lesser version
hopes a "perfectly free" AI will arrive at virtue), with John C. Wright as the example.
