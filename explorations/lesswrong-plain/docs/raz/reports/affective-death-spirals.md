# Report: affective-death-spirals

## 1. The argument in three sentences

A favoured theory used to explain more and more seems truer and gets applied more widely,
but a worse cycle starts from a thought that feels good: by the halo effect, each positive
perception raises others, like neutrons in a fission chain reaction. Weak affect is
subcritical and dies out; intense affect attached to a "Great Thingy" reaches everything, as
when a believing Communist sees Marx confirmed in every event and enjoys it, and so seeks new
occasions to apply the idea. The author names this the "affective death spiral" and promises
a remedy in the next post.
