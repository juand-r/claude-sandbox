# Report: amazing-breakthrough-day-april-1st ("Amazing Breakthrough Day: April 1st", Yudkowsky, posted 2008-03-25; book order 212)

## 1. The argument in three sentences (written before annotating)

The post proposes that on April 1st journalists report old, understandable scientific
breakthroughs as if they had just happened, using the day's reputation for hoaxes as cover.
Its reason is that science news covers only the frontier, where findings are often
controversial, hard and later shown wrong, so readers never see the solid, understandable
science beneath. It adds that online readers already reward good explanations of old science,
so a new explanation should count as news, and it offers the holiday as a modest first step.
