# Report: categorizing-has-consequences

## 1. The argument in three sentences

Blood types are real, medically important categories discovered by Landsteiner, yet in
Japan they carry personality stereotypes like astrological signs; since blood types were
never mysterious and never the lines of a conflict, the author argues the stereotypes "must
have arisen strictly from the mere existence of the labels". The author predicts, without
knowing of an experiment, that labeling non-human things would have the same effect, and
explains the effect four ways (similarity clusters, neural subnetworks, compression, the
ability to make things up about any named category). So drawing a category boundary is never
a neutral act for a human mind, which is one more reason not to believe you can define a word
any way you like.
