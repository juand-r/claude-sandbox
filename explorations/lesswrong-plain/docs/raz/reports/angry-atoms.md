# Report: angry-atoms ("Angry Atoms", Yudkowsky, posted 2008-03-31; book order 219)

## 1. The argument in three sentences (written before annotating)

We cannot see the identity between quarks and hands, but we can at least imagine atoms
pushing on things; anger looks like a different kind of thing altogether, and to someone
without the idea of computation (a hunter-gatherer) the gap between billiard balls and angry,
plotting behaviour would look uncrossable. The gap is not crossed by saying "neurons process
information" or "anger is hormones", which only insert an unexplained level-crossing rule or
invite the false conclusions that anger is unjustified or unreal; it is crossed by specific
insights such as search trees and utility functions, which show how a merely causal system
can compute plans (as a chess program does), and so how alcohol acting on such a system could
produce angry behaviour. This is only a practice problem, since it concerns behaviour and not
experience, but it shows that explanatory gaps can be crossed if one accepts help from
science rather than trusting the view from inside one's own mind.

## 6. Judgment calls

1. The Lucretius note is information, not criticism. The last sentence ("explains anger by a kind
   of particle rather than by an arrangement of particles") is my description of the passage.
2. The note on "All this is still tremendously oversimplified" says the step from planning to
   anger is "asserted in one sentence about alcohol". The post hedges it; the note says so. The
   Response repeats this as "the thinnest part". A defender may call it any-essay-does-that; I
   kept it because the post's question was about anger in particular.
3. The Chalmers note and Response paragraph: the post's opponents already grant the behavioural
   case. This is a scope point. The post itself says the example is easy and concerns only
   behaviour, and the Response credits that. "A leading non-materialist" is my characterization
   of Chalmers.
4. The conclusion note: "can be crossed" needs only one crossing, so the claim holds as stated.
   I did not fault it.
5. Pronouns: Lucretius, Levine and Chalmers are named rather than given pronouns.
