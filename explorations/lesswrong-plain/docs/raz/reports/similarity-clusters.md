# Report: similarity-clusters

## 1. The argument in three sentences

No list of necessary and sufficient features captures everything humans share, as
Diogenes' plucked chicken showed for Plato's "featherless biped." A rough definition is
still useful: it picks out some real examples, from which we learn many more shared
characteristics, so that the category becomes a "similarity cluster" and a plucked chicken
no longer fits, whatever the definition says. So a definition is a clue that leads to a
cluster, and a dictionary is a book of hints for matching words to clusters, not a book of
Aristotelian class definitions.

## 6. Judgment calls

   counterexample to "featherless biped" as a definition peculiar to man, so the word is met
   under Aristotle's rule.

   human psychology"). A fair defender could say it means mechanical application of a
   definition, not Aristotle's full practice. The note says "narrowly" and grants that the
   Aristotelian rule presupposes recognition, which supports the post.
