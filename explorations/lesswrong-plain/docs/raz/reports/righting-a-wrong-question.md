## 1. The argument in three sentences (written before annotating)

Replace "Why X?" with "Why do I think X?": the second question always has an answer, because
the belief is a real event with a causal history, whether or not X is true or even coherent.
Tracing that history step by step, in non-confusing terms, either reaches the fact (the socks)
or reaches an algorithm that runs skew to reality (the mirage). So cognitive science, unlike
metaphysics, offers questions that are guaranteed solvable.
