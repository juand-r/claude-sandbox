# Report: variable-question-fallacies

## 1. The argument in three sentences

"Either P or not-P" holds only if P stands for exactly the same thing in both halves, so
"either the tree makes a sound or it does not" fails when Albert's "sound" and Barry's
"sound" are different concepts. Many words, like "left", are functions of hidden context
variables, and when a question's hidden variable takes different values in different
contexts, it feels as if reality itself were unstable, a feeling the author traces to how
the mind's categorizing algorithm feels from inside. Such a sentence does not have a
variable truth value; like "2 + 2 = X", it has no truth value until the variable is fixed.
