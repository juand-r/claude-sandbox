# Third pass: removing notes that are not sensible criticism

Request (user): "Some of the comments/footnotes do not really look like sensible criticism.
Those should be removed."

A note is removed when it does one of these:
1. Takes a joke, figure of speech or obvious hyperbole literally.
2. Nitpicks wording that does not affect meaning (word counts, an intensifier, a
   metaphor mix, chat register, a coinage) with no consequence for the argument.
3. Reads motives or effects into the text with no textual basis ("exists to make the
   reader feel superior", "exists to carry links").
4. Faults the post for something any short essay does (an anecdote, a hypothetical,
   an invented example flagged as invented, not citing a standard source for a
   commonplace).
5. Rests on a contrived or speculative objection.

Kept: factual corrections, misquotations, arithmetic, and objections to the argument
itself. Where one sentence of a note fails the test and the rest is sound, only that
sentence goes.
