1 · Regression trees

A regression tree

  • Like a decision tree, each node compares a feature with a threshold. A categorical feature gets one branch per value.
  • Each leaf predicts a number: the average y of the training points that reach it.

0The same dosage data.

1A tree with three questions about the dosage. Internal nodes ask a question; leaves give an answer, here a number instead of a class.

2Each leaf owns an interval of dosages. Its prediction is flat across that interval.

3Example: dosages between 23.5 and 29 mg. Four training points land in this leaf; their average effectiveness, (66 + 60 + 50 + 45)/4 = 55.25, is the prediction.

1 · Regression trees

Choosing a split

  • Sort by the feature. Try a threshold between each pair of neighbors.
  • Each side predicts its average y. Score the threshold by the sum of squared errors:SSE = Σ (yᵢ − ŷᵢ)²
  • The SSE curve has more than one dip. Try every threshold.
  • Keep the one with the smallest SSE.

0How do we pick the first question? With class labels we looked for a change of label. Here there are no labels, so every gap between neighbors is a candidate.

1First candidate: 3 mg, between the first two points. Left side: one point, mean 0. Right side: the other 17, mean 38.7. The orange segments are the errors; square them and add them up over all 18 points.

2One dot per candidate threshold. The curve is not a single bowl: the SSE rises near 20 mg, where a split cuts the high plateau in two and mixes high and low points on each side. So there is no formula for the minimum; we try them all.

3The best threshold is 14.5 mg, SSE ≈ 19,500. That is the root of the tree. Trying every threshold is cheap: moving the threshold one point to the right moves one point from one average to the other.

1 · Regression trees

Grow, then stop

  • Split each side the same way, and repeat.
  • Grown all the way, the tree reproduces every training point. It overfits.
  • Stop early: do not split a node with 6 or fewer points. A maximum depth also works.
  • Stop too early and the tree underfits.
  • Tune the stopping rule with nested cross-validation.

0After the root split, each side is a smaller dataset. Run the same search on it: every feature, every threshold, smallest SSE.

1Never stopping: training SSE 0. Every point has its own leaf, except where neighbouring points have the same y (14 leaves for 18 points). That is memorization.

2The rule used for the tree two slides ago. Left of 14.5 mg there are 6 points: a leaf. Right of it, 12 points: split at 29 mg. Above 29 mg, 4 points: a leaf. Between 14.5 and 29 mg, 8 points: split at 23.5 mg, then both sides are small enough. The minimum number of points needed to split is the hyperparameter used most often for regression trees; max depth works too, and they can be combined.

3Require 19 points and the root cannot split: one leaf, the overall average, 36.6.

4Try several values and keep the one with the lowest SSE on the validation folds.

1 · Regression trees

Many features

  • For each feature, find its best threshold. Keep the feature and threshold with the smallest SSE.
  • A feature with two values, like F / M, has only one split.
  • More values, like single / married / divorced: one-hot encode, and try each value against the rest.

2 · kNN regression

kNN regression

  • To predict at x, find the k training points nearest to x. Predict the average of their y.
  • Do this at every x to get the regression curve.
  • Small k follows every point. With k = 1 the curve passes through the data: it overfits.
  • Large k smooths. Too large underfits. Tune k with nested cross-validation.

3 · Support vector regression

Support vector regression

  • SVM classification: the widest margin between the classes.
  • SVR: a tube of fixed half-width ε around the line w · x + b. The line is the prediction. Points inside the tube cost nothing.
  • A point outside the tube has slack ξ: its vertical distance beyond the tube.
ε
outside the tube
total slack

0Data with a roughly linear trend. For classification we wanted the widest margin with the points outside it. For regression we want the points inside.

1We choose ε, the error we are willing to tolerate: predictions within ε of the truth count as right. ε is measured vertically, in units of y, because it is an error in y. Here ε = 2.

2Points above the tube and below it both get slack, always positive. Same idea as the soft-margin SVM, but measured vertically rather than perpendicular to the line.

3 · Support vector regression

The SVR problem

minimize ½ ‖w‖² + C Σ (ξᵢ + ξᵢ*)
subject to
yᵢ − (w · xᵢ + b) ≤ ε + ξᵢ
(w · xᵢ + b) − yᵢ ≤ ε + ξᵢ*
ξᵢ ≥ 0, ξᵢ* ≥ 0
  • The tube width is fixed, so ½ ‖w‖² keeps the slope small. A flatter model is less likely to overfit.
  • Large C: slack is expensive. Steeper fits that chase the points: more variance.
  • Small C: slack is cheap. Flatter fits: more bias.
  • C and ε are hyperparameters.

0Same shape as the soft-margin SVM. The constraints say: the error is at most ε, plus slack. ξᵢ is for points above the tube, ξᵢ* for points below. C = 0.1, ε = 2.

1In classification, minimizing ½‖w‖² widened the margin. Here the width is fixed, so it does something else: it keeps the coefficients small. As with linear regression, steep models are more likely to overfit.

2C = 10: the solver avoids slack and accepts a steeper line. A steeper line reacts more to changes in x: more variance.

3C = 0.01: slack is cheap, so the slope shrinks towards zero and many points fall outside the tube. Low variance, high bias: we are imposing an assumption, flatness, on the data.

4Tune C, and ε too, with nested cross-validation, looking for the balance of bias and variance.

3 · Support vector regression

Nonlinear SVR

  • So far SVR fits a line, or a hyperplane with many features.
  • Same fix as for SVMs: replace dot products with a kernel. The fit is linear in hidden features and curved in the original one.
  • Choose the kernel and its settings, with C and ε, by grid search in nested cross-validation.

0Back to the dosage data. C = 1000 and ε = 5 on this slide.

1A linear SVR: a straight tube cannot follow the rise and fall.

2The RBF kernel, K(x, x′) = exp(−γ (x − x′)²), with γ = 0.02. Think of mapping the data into a new space, fitting a linear SVR there, and mapping the fit back: it is curved. The kernel does this without computing the new features.

3γ = 0.2: the curve bends more sharply around individual points. As with classification, a larger γ can overfit. Try several kernels and settings, like the list of kernels in the homework, and keep the best on validation data.

Summary

Takeaways

Regression trees

Split where the SSE is smallest. A leaf predicts the average y of its points.

Hyperparameters: minimum points to split, maximum depth.

kNN regression

Predict the average y of the k nearest training points.

Hyperparameter: k.

Support vector regression

A tube of half-width ε; points outside it pay slack. A kernel makes it curve.

Hyperparameters: C, ε, kernel.

Each hyperparameter moves the model between underfitting and overfitting. Tune it with nested cross-validation.

Three classifiers, three regressors. In each the hyperparameter controls how closely the model follows the training points.
