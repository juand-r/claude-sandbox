0Ask the class: for each method we have seen, what did it make as small as possible?

1Linear regression: the sum of squared differences between the true and predicted values.

2PCA: the squared distance from each point to its projection onto the chosen components. Minimizing it is the same as keeping as much variance as possible.

3SVM: a wide margin (small ‖w‖) and as little slack as possible, traded off by C.

4Different methods, different losses. Today: what loss should a classifier use?

5Every method has a model: a formula that turns an input into a prediction, with parameters θ to be chosen.

6And a loss that scores each choice of θ on the training data. Training is finding the θ with the smallest loss.

If asked "what is the model in each case?": Linear regression: ŷᵢ = w · xᵢ + b, so θ = (w, b). PCA: the prediction is the reconstruction x̂ᵢ = μ + V Vᵀ(xᵢ − μ), where V holds the k component directions as orthonormal columns and μ is the mean; θ = V (and μ). It is unsupervised: the model predicts each point from only k numbers. SVM: the score f(xᵢ) = w · xᵢ + b and the prediction ŷᵢ = sign(f(xᵢ)), so θ = (w, b); the slacks ξᵢ are extra variables the optimizer also sets, but they are determined by w and b.

Minimize the training error?

  • Binary case: each prediction is right or wrong.
  • For a threshold t, we wantf(xᵢ) > t for yᵢ = +1f(xᵢ) < t for yᵢ = −1f is a score or a probability.
  • Count the points that break their condition: the training error.
  • The 0–1 loss is:ℒ = Σ 𝟙[yᵢ f(xᵢ) ≤ 0]𝟙[·] is 1 if true, 0 if false. Here f is a score with t = 0.

0Rows are the true class, columns the prediction. Two ways to be right, two ways to be wrong.

1Positives should score above the threshold, negatives below it. Same picture as the ROC lecture.

2The natural loss for a classifier: the number of training mistakes.

3With a score and t = 0, multiply by the label and both conditions become one: y·f(x) > 0 means correct, so y·f(x) ≤ 0 is a mistake. Each mistake costs 1, each correct point 0. y·f(x) is the horizontal axis of the next slide.

If asked "why not minimize the 0–1 loss directly?": (1) It gives no direction. Nudging w usually changes no prediction, so the count stays flat and then jumps; there is no slope to follow. (2) It is computationally hard: finding the line with the fewest training mistakes is NP-hard in general, as the number of features grows (Ben-David, Eiron and Long, 2003). (3) It has no preference among the many lines with the same count, for example for a wide margin. So we minimize a smooth or convex stand-in that is easy to minimize and still punishes mistakes: the hinge loss, or the log loss.

Recap

The SVM as a loss

  • The score f(x) = w · x + b. Its sign is the prediction; y f(x) > 0 means correct.
  • Each point pays the hinge loss:max(0, 1 − y f(x))
  • The soft-margin SVM:minimize ½ ‖w‖²
    + C Σ max(0, 1 − yᵢ f(xᵢ))
  • Points beyond the margin pay nothing.

━ 0–1 loss (mistake or not)━ hinge loss

0Horizontal axis: y·f(x), the score times the true label. Positive means correct; at least 1 means outside the margin. The 0–1 loss counts mistakes.

1The hinge is zero from 1 on and grows linearly below 1. Mistakes cost more the further they are on the wrong side.

2At the solution the slack ξᵢ equals the hinge loss of point i (the bonus slide at the end of the SVM deck), so the soft-margin SVM reads as "fit the data, keep w small".

3Once a point is past the margin it has no influence. Only points on or inside the margin, the support vectors, matter.

Same score, another loss

Log loss

  • Replace the hinge with the log loss:log(1 + e−y f(x))
  • It is never exactly zero: every point counts a little. Far on the wrong side it grows linearly, like the hinge.
  • Logistic regression:minimize ½ ‖w‖²
    + C Σ log(1 + e−yᵢ f(xᵢ))

━ 0–1 loss━ hinge loss━ log loss

0Same horizontal axis. The new curve is smooth: no corner at 1.

1Correct points far from the boundary still pay a tiny amount, so all points have some say in where the line goes, not only the support vectors.

2Same form as the SVM: a loss on the data plus a penalty on w, with C trading them off. This is exactly what scikit-learn's LogisticRegression minimizes (the intercept is not penalized). Why this loss? The next slide.

From score to probability

The sigmoid

  • The sigmoid squashes any score into (0, 1):σ(z) = 1 / (1 + e−z)
  • Logistic regression reads the score as a probability:p(y = +1 | x) = σ(w · x + b)
  • The probability of the true class is σ(y f(x)).
  • So the log loss is −log p(true class). Confident and wrong costs a lot.

0Score 0 gives 0.5. Large positive scores give probabilities near 1, large negative near 0.

1Same linear score as before. The sigmoid changes how we read it, not where the boundary is.

2For y = −1: p(y = −1) = 1 − σ(f) = σ(−f). So in both cases the true class gets σ(y·f).

3−log σ(y f) = log(1 + e^(−y f)), the log loss of the last slide. Minimizing it makes the model give high probability to what actually happened. A point predicted at 0.01 for its true class costs −log 0.01 ≈ 4.6.

Working it out

Sigmoid and log loss

The true class gets σ(y f)

p(y = −1) = 1 − σ(f)
= e−f / (1 + e−f)
= 1 / (ef + 1)
= σ(−f)

Its −log is the log loss

−log p(true class)
= −log σ(y f)
= −log [1 / (1 + e−y f)]
= log(1 + e−y f)

using −log(1/a) = log a

The inverse of the sigmoid

p = 1 / (1 + e−z)
1 + e−z = 1/p
e−z = (1 − p) / p
z = log(p / (1 − p))

The score w · x + b is the log-odds of the positive class.

0Why the true class gets σ(y·f): for y = +1 it is σ(f) by definition. For y = −1, multiply the top and bottom of e^(−f)/(1 + e^(−f)) by e^f. So one formula covers both classes.

1Take −log of that probability. The sigmoid is one over something, and −log of one over a is log a. Out comes exactly the log loss of slide 5. Minimizing log loss means giving high probability to the true class of every training point.

2Now run the sigmoid backwards: given a probability p, which score z produced it? Solve for z. The answer, log(p/(1 − p)), is called the log-odds or logit.

3So the linear score has a meaning: it is the log-odds. A score of 0 is even odds, p = 0.5; each extra unit of score multiplies the odds by e ≈ 2.7. Logistic regression models the log-odds as a linear function of x; that is where "regression" in the name comes from.

One feature

A fitted model

  • The fitted curve gives a probability for every x.
  • Predict positive when p ≥ 0.5, that is, when w · x + b ≥ 0.
  • Any other threshold works too. Each one is a point on the ROC curve.

Two features

Still a hyperplane

  • The boundary p = 0.5 is the hyperplane w · x + b = 0. Probability changes smoothly across it.
  • The SVM, on the same data, draws a different line: only its support vectors count.
  • Both give a score you can threshold. Logistic regression's score is a probability.

3An SVM can be given probabilities too, by fitting a sigmoid to its scores afterwards (Platt scaling). Logistic regression has them built in.

Summary

Takeaways

Same score

Logistic regression and the linear SVM both use f(x) = w · x + b and draw a hyperplane.

Different loss

Hinge loss for the SVM, log loss for logistic regression. Each adds ½ ‖w‖².

A probability

The score becomes a probability, p = σ(f(x)). Threshold it at 0.5, or anywhere else.

Logistic regression is a classifier with a probabilistic score, and a single neuron. Next week we stack them.
